# Security Policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a security issue

Use GitHub's private vulnerability reporting feature when it is available for this repository.

Do not include Threads cookies, passwords, login tokens, private messages, private handle lists, screenshots with personal information, or other credentials in an issue or test case.

If private reporting is unavailable, open a short GitHub issue that identifies the affected function and the type of risk. Do not include a working exploit against another person's account or any private data.

Useful reports explain:

- Which script version is affected.
- Which Threads interface language was active.
- What safe steps reproduce the selector or state error.
- Whether an action was sent or only appeared possible.
- What result you expected.

This project does not offer a bug bounty.
